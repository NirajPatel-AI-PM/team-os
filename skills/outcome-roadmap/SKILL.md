# Outcome roadmap

1. Group the requested features by the outcome each one serves. A feature that serves no outcome goes in a separate list and is discussed first.
2. For each outcome write: the metric, its value today, the target, and the date.
3. Under each outcome list the bets, ranked with the `team-os:rice` skill.
4. Mark each bet as now, next or later. Only "now" gets a date.
5. Record the outcome from last month's review: which metrics moved, which did not, and what changes because of it.

Run the review monthly with engineering, program management and leadership in the room. Start with step 5.
